- 🏢 Database-per-tenant isolation on MongoDB via a Prisma tenant-routing proxy (`AsyncLocalStorage`)
- 🔐 Google OAuth + WebAuthn passkeys, CSRF, RBAC, login-risk scoring with impossible-travel detection
- 🤖 AI chatbot & AI insights via a local Ollama LLM with a tool-calling loop; AI resume scoring
- ⚡ BullMQ background jobs, two-tier (in-memory LRU + Redis) caching, Socket.IO real-time updates
- 📊 Prometheus + Grafana + Loki observability with OpenTelemetry tracing
- 💳 Razorpay subscription billing with webhook-driven lifecycle
